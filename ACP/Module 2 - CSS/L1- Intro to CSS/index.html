History of CSS

CSS (Cascading Style Sheets) was first proposed by Håkon Wium Lie in 1994, with the goal of separating the style and presentation of web content from the HTML structure. It became a W3C Recommendation (CSS1) in 1996, marking the beginning of its official standardization. Subsequent versions, like CSS2 (1998) and the ongoing CSS3, have expanded its capabilities, including layout control, media types, and modular development.
